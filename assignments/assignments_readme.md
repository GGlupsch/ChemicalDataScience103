# General information on assignments

To fortify and deepen the lecture content, throughout the course, you will receive several assignments, uploaded after their announcement in the lecture to the ``assignments folder`` in this repo. Attempting these assignments is required in order to be admitted to the exam. Please note that one of these homework assignments will be replaced by a small project introduced in session 17 that you have three weeks instead of one week to work on.

In order to complete an assignment, all tasks in the assignment description/notebook need to be carried out. The assignment will be counted as complete if all relevant steps in the task are carried out and the questions in the end are answered. Code needs to be executable without errors using the DSA 103 environment.

The assignments are to be submitted to dimitrios.xynos@chem.uzh.ch by 7:59 am on the following Friday with the subject "DSA103_26_Ex1_LastName_FirstName". Afterwards, the solutions will be uploaded into this folder. If the deadline should change, we will notify you accordingly.

After submitting your solutions, you will receive feedback. Our TA Dimitrios is happy to join our Q&A sessions for more detailed, specific discussions on assignments and your solutions - simply let us know before the next Q&A session if you wish for this.
